# Интерактивный рабочий лист «Квадратные уравнения»

Готовый статический сайт на HTML/CSS/JS. Можно разместить на GitHub Pages. Ответы учеников отправляются в Google Таблицу через бесплатный Google Apps Script.

## Что внутри

- определение квадратного уравнения и формула `ax² + bx + c = 0`;
- коэффициенты `a`, `b`, `c`;
- полные, неполные и приведённые квадратные уравнения;
- способы решения;
- интерактивные раскрывающиеся блоки про дискриминант и теорему Виета;
- сюжетное объяснение теоремы Виета;
- мини-тест из 5 вопросов;
- задание по Виету с заполнением пропусков;
- задание через дискриминант с заполнением шагов;
- персональный вариант, который зависит от имени и класса ученика;
- автоматическое сохранение черновика в браузере;
- отправка результата и всех введённых ответов преподавателю.

## 1. Подключить сохранение в Google Таблицу

1. Создайте новую Google Таблицу. Название может быть любым, например `Квадратные уравнения - ответы`.
2. В таблице откройте `Расширения -> Apps Script`.
3. Удалите стандартный код и вставьте содержимое файла `apps-script.gs`.
4. Нажмите `Сохранить`.
5. Нажмите `Развернуть -> Новое развертывание`.
6. Тип: `Веб-приложение`.
7. `Выполнять от имени`: ваш аккаунт.
8. `У кого есть доступ`: `Все`.
9. Нажмите `Развернуть` и разрешите доступ.
10. Скопируйте адрес веб-приложения. Он должен заканчиваться на `/exec`.
11. Откройте `script.js` и замените:

```js
const SUBMIT_URL = "PASTE_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE";
```

на ваш URL.

После первой отправки скрипт сам создаст лист `Ответы` и заголовки столбцов.

## 2. Опубликовать через GitHub Pages

Если файлы лежат в папке `quadratic-equations` репозитория `form`, итоговый адрес будет иметь вид:

`https://ВАШ-ЛОГИН.github.io/form/quadratic-equations/`

Чтобы включить Pages:

1. GitHub -> репозиторий `form` -> `Settings`.
2. Слева откройте `Pages`.
3. В `Build and deployment` выберите `Deploy from a branch`.
4. Branch: `main`, Folder: `/(root)`.
5. Сохраните.

## Проверка перед выдачей ученикам

1. Откройте опубликованный лист.
2. Введите тестовое имя и класс.
3. Заполните ответы и нажмите `Проверить и отправить`.
4. Откройте Google Таблицу и убедитесь, что появилась строка.
5. После этого ссылку можно отправлять ученикам.

## Как устроена защита от простого списывания

- вариант определяется из имени + класса и остаётся стабильным для этого ученика;
- у задания по Виету 8 вариантов;
- у задания по дискриминанту 8 вариантов;
- 5 тестовых вопросов выбираются из банка 12 вопросов;
- варианты ответов в тесте перемешиваются;
- после проверки правильные числа для практических заданий не выводятся.
