01 • ОСНОВА

Что такое квадратное уравнение?

!

Квадратное уравнение - это уравнение вида ax² + bx + c = 0, где a, b, c - числа, а a ≠ 0.

Главный признак темы - неизвестное x встречается во второй степени. Коэффициент a не может быть равен нулю, иначе член с x² исчезнет и уравнение перестанет быть квадратным.

a

Старший коэффициент

Стоит перед x² и определяет, как ведёт себя парабола.

b

Коэффициент при x

Стоит перед x. Может быть положительным, отрицательным или нулём.

c

Свободный член

Число без x. Оно тоже может быть равно нулю.

-3x² + 5x - 7 = 0
a = -3b = 5c = -7
02 • ВИДЫ

Полное, неполное и приведённое

Нажимай на карточки. Внутри - короткое правило, пример и подсказка, как быстро узнать вид уравнения.

Полное квадратное уравнение+

Все три коэффициента a, b и c не равны нулю.

2x² - 7x + 3 = 0

Проверка: есть x², есть x и есть отдельное число.

Неполное квадратное уравнение+

Хотя бы один из коэффициентов b или c равен нулю.

3x² - 12 = 05x² + 10x = 0

Часто такие уравнения можно решить быстрее дискриминанта: вынесением x или переносом числа.

Приведённое квадратное уравнение+

Старший коэффициент равен единице: a = 1.

x² + px + q = 0

Для такого уравнения особенно удобно использовать теорему Виета.

Теорема Виета: история про двух напарников+
СЮЖЕТ

Представь, что корни x₁ и x₂ - два напарника, которых мы пока не знаем. У них есть две улики: вместе они дают нужную сумму, а при умножении - нужное произведение. Нужно найти пару чисел, которая одновременно подходит под обе улики.

Для приведённого уравнения x² + px + q = 0:

x₁ + x₂= -p
x₁ · x₂= q
Пример без раскрытия твоего задания
x² - 5x + 6 = 0

Нужны два числа, сумма которых равна 5, а произведение равно 6. Подходит пара 2 и 3, значит корни: x₁ = 2, x₂ = 3.

Неполные уравнения: когда можно быстрее+
Если c = 0

ax² + bx = 0

Вынеси x: x(ax + b) = 0.

Если b = 0

ax² + c = 0

Перенеси c и найди x².
