МИССИЯ 01

Где нужна переменная?

Нажми «Нужна» или «Не нужна». Смотри не на важность данных, а на то, меняется ли значение во время игры.

Главная идея: переменная особенно полезна там, где программе нужно помнить значение, которое может изменяться.

Почему старое значение исчезает?

Переменная хранит одно текущее значение. Новая команда обновляет его — следующее действие работает уже с новым состоянием.

БылоЖизни = 3
→
Командаизменить на -1
→
СталоЖизни = 2
Фраза для закрепления: переменная не хранит всю историю значений сама по себе — она хранит актуальное значение. Если нужна история, её нужно записывать отдельно.
Сначала пройди две миссии.
