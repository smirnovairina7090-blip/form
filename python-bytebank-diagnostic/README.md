# ByteBank - диагностика Python

Сюжетный интерактивный рабочий лист для оценки уровня Python ученика. Статический сайт подходит для GitHub Pages.

## Что проверяет

- базовый синтаксис и операторы;
- условные конструкции;
- циклы `for` и `while`;
- строки;
- списки;
- словари;
- функции;
- чтение и восстановление кода;
- три коротких задания на самостоятельное написание кода;
- бэкграунд и интересы ученика.

Максимум - 30 баллов. Результат дополнительно раскладывается по темам.

## Подключение Google Таблицы

Таблица уже создана: https://docs.google.com/spreadsheets/d/1zrUoAwahtWzXlfatGsvoAak9OQZvK3hYE0hyroWDYrs/edit

1. В Google Таблице откройте `Расширения -> Apps Script`.
2. Замените содержимое редактора кодом из `Code.gs`.
3. Нажмите `Развернуть -> Новое развертывание -> Веб-приложение`.
4. Выполнять от имени: владелец. Доступ: все, у кого есть ссылка.
5. Скопируйте URL веб-приложения вида `https://script.google.com/macros/s/.../exec`.
6. В `script.js` вставьте этот URL в константу `SUBMIT_ENDPOINT` в первой строке.
7. Сделайте commit. После этого кнопка завершения будет автоматически добавлять строку в таблицу.

Пока endpoint не указан, диагностика полностью считает результат локально и сохраняет черновик в браузере, но в Google Таблицу ничего не отправляет.
