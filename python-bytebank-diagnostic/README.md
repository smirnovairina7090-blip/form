# ByteBank - диагностика Python

Сюжетный интерактивный рабочий лист примерно на 40 минут. Ученик проходит рабочую смену стажёра отдела автоматизации банка: читает сообщения сотрудников, открывает журналы и карточки операций, разбирает сбои, работает с клиентскими данными и в финале пишет короткие фрагменты Python самостоятельно.

Диагностика анонимная: имя, класс и возраст не запрашиваются. Вместо этого собираются стартовые ощущения от программирования, реакция на ошибки, прошлый опыт, интересы, желаемое направление развития, ощущения после смены и понравившийся тип задач.

## Что проверяет

- базовый синтаксис и операторы;
- условные конструкции и логические выражения;
- циклы `for` и `while`;
- строки;
- списки;
- словари;
- функции;
- поиск и исправление ошибок;
- чтение и восстановление кода;
- три коротких задания на самостоятельное написание кода.

Максимум - 40 баллов. Результат дополнительно раскладывается по темам.

## Сюжет

Внутри есть сотрудники ByteBank: Мира из отдела автоматизации, Кирилл из поддержки, Соня из антифрода и Тимур из продуктовой команды. Всплывающие окна показывают рабочий чат, журнал банкомата, карточку подозрительной операции, клиентскую запись и сообщение колл-центра.

## Подключение Google Таблицы

Таблица результатов: https://docs.google.com/spreadsheets/d/1zrUoAwahtWzXlfatGsvoAak9OQZvK3hYE0hyroWDYrs/edit

1. В Google Таблице откройте `Расширения -> Apps Script`.
2. Замените содержимое редактора кодом из `Code.gs`.
3. Нажмите `Развернуть -> Новое развертывание -> Веб-приложение`.
4. Выполнять от имени: владелец. Доступ: все, у кого есть ссылка.
5. Скопируйте URL веб-приложения вида `https://script.google.com/macros/s/.../exec`.
6. В `script.js` вставьте этот URL в константу `SUBMIT_ENDPOINT` в первой строке.
7. Сделайте commit. После этого кнопка завершения будет автоматически добавлять строку в таблицу.

Пока endpoint не указан, диагностика полностью считает результат локально, показывает карту навыков и сохраняет черновик в браузере, но в Google Таблицу ничего не отправляет.
